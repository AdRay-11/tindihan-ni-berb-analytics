# Data (not committed)

Download **Online Retail.xlsx** from the UCI Machine Learning Repository
(https://archive.ics.uci.edu/dataset/352/online+retail, doi:10.24432/C5BW33) and place it here.

The Phase 1 cleaning steps (documented in `reports/Phase1_Business_Data_Preparation.pdf`) produce these files in this folder:
`basket_matrix.csv`, `customer_rfm.csv`, `customer_rfm_scaled.csv`, `cancellations.csv`.

Customer-level files are kept out of Git on purpose (see `.gitignore`).
